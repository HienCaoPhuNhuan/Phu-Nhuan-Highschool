# THPT Phú Nhuận — Website mẫu cho học sinh

Website mẫu phục vụ hoạt động học tập HTML, CSS, JavaScript và triển khai bằng GitHub Pages.

## Mục tiêu

Học sinh sử dụng repository này như một điểm bắt đầu để:
- chỉnh sửa nội dung HTML;
- tùy biến giao diện bằng CSS;
- thêm tương tác đơn giản bằng JavaScript;
- kiểm tra khả năng hiển thị trên máy tính và điện thoại;
- triển khai sản phẩm bằng GitHub Pages.

## Cấu trúc

```
Phu-Nhuan-Highschool/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Bài tập gợi ý

1. Thay đổi phần giới thiệu theo chủ đề của nhóm.
2. Đổi bảng màu nhưng vẫn đảm bảo dễ đọc.
3. Thêm ít nhất 4 hình ảnh.
4. Tạo thêm ít nhất 1 mục nội dung mới.
5. Kiểm tra website ở màn hình điện thoại.
6. Xuất bản bằng GitHub Pages và nộp URL.

## Bật GitHub Pages

Vào **Settings → Pages → Build and deployment → Deploy from a branch**.

Chọn:
- Branch: `main`
- Folder: `/(root)`

Sau đó bấm **Save**.

Địa chỉ dự kiến:

`https://hiencaophunhuan.github.io/Phu-Nhuan-Highschool/`

## Lưu ý cho học sinh

Không đưa mật khẩu, số điện thoại cá nhân, dữ liệu nhạy cảm hoặc thông tin riêng tư lên repository public.
