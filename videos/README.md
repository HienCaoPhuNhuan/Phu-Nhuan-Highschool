# Video assets

Đặt video giới thiệu của bạn tại đường dẫn:

`videos/school.mp4`

Website trang chủ đã được cấu hình để tự động phát hiện file này và hiển thị trình phát HTML5.

Khuyến nghị:
- Định dạng MP4 (H.264)
- Tỉ lệ 16:9
- Nén dung lượng trước khi upload
- Không đưa dữ liệu cá nhân hoặc nội dung chưa được phép công khai lên repository public
